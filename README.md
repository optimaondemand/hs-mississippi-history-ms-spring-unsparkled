# Mississippi History Spring: unsparkled (plain) lessons

Plain originals of every lesson and primary-source page in `optimaondemand/hs-mississippi-history-ms-spring`, at the same paths, served on GitHub Pages. The plain lesson pages in the `(Unsparkled)` Canvas modules embed these files.

Nothing in this repo is ever edited, and no sparkled file is ever pushed here. Weeks 19 and 20 were recovered from the lesson repo's git history (lessons at 3a513243, primary sources at 1d6cedea); weeks 21 to 36 were copied from `main` while still plain.
